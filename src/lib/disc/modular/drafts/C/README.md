# Conformidade — rascunhos das quatro variações

Este lote contém 92 textos novos: 46 Premium e 46 Técnico, nas 23 células válidas por biblioteca. Cada variação mantém Título, Leitura, Ponto de atenção e Ação. Os exemplos das variações 3 e 4 diferem entre si em cada célula.

As variações 1 e 2 das amostras não foram recuperadas literalmente. Por autorização posterior do usuário, foram redigidos 92 novos textos (46 Premium e 46 Técnico) nos arquivos `C-premium-v1-v2.json` e `C-technical-v1-v2.json`, sem apresentá-los como originais aprovados. Com os arquivos anteriores, cada biblioteca contém 23 diagnósticos com quatro variações, totalizando 184 textos. Os arquivos das variações 3 e 4 permanecem intactos. Os exemplos novos foram comparados com os anteriores; a conferência de frases literais incluiu os rascunhos dos demais fatores.

Os arquivos não são importados pelo compositor em execução. A chave de transição permanece desligada; textos atuais, motor de cálculo, faixas, classificação, apresentações e impressão não foram alterados. Nada foi ativado ou publicado.
